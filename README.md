# 양수길 — 포트폴리오 홈페이지

사내 업무 자동화 실적을 소개하는 개인 포트폴리오. **`index.html` 파일 하나로 동작**합니다.
(외부 CSS/JS 파일 없음 · 폰트만 CDN 사용)

## 1. 내용 수정하기

`index.html` 을 열면 `<head>` 안쪽에 데이터 상수 블록이 있습니다. **이 블록만 고치면 됩니다.**
아래쪽 렌더링 코드는 건드릴 필요가 없습니다.

| 상수 | 바뀌는 곳 |
|---|---|
| `PROFILE` | 첫 화면의 이름 · 직함 · 타이핑되는 제목 문구(`rotate`) · 소개 · 태그 |
| `DEMOS` | 첫 화면 프롬프트 데모 (요청 → 생성된 시스템) 4건 |
| `ABOUT` | '한눈에' 벤토 — 해외 사이트 · 인정 · AI 협업 흐름 |
| `CHAT` | Ch.05 AI 협업 대화 (실제 진행 흐름 재구성) |
| `CATEGORIES` | 프로젝트 필터 탭 |
| `projects` | **프로젝트 카드 (여기에 객체를 추가하면 카드가 자동으로 늘어남)** |
| `status` | 각 프로젝트의 `'live'`(운영 중) / `'soon'`(도입 예정) 상태 |
| `TEXT` | 각 챕터의 제목과 설명 문구 |
| `BANDS` | 각 파트 앞 전면 영상 구간의 라벨 · 제목 · 부제 |
| `PROBLEMS` | Ch.01 문제 카드 3개 |
| `TIMELINE` | Ch.02 확산 타임라인 |
| `BARS` / `NOTES` | Ch.04 Before→After 막대 / 산출 근거 각주 |
| `WAYS` | Ch.05 일하는 방식 4단계 |
| `STACK` | 기술 스택 |
| `CONTACT` | 연락처 (지금은 비어 있음 → 값을 채우면 자동 표시) |
| `REPRO_BADGE` | 카드 이미지의 `재현 화면` 표시 on/off |

### 프로젝트 카드 추가
`projects` 배열에서 객체 하나를 통째로 복사해 붙여넣고 값만 바꾸면 됩니다.
배열 순서 = 화면 표시 순서. 필터 탭의 개수와 Ch.04 합계(절감 시간·환산 구축비)는
`hours` / `est` 값에서 **자동 계산**됩니다.
합계에는 `status: 'live'` 인 프로젝트만 반영됩니다. `'soon'`(도입 예정)은 카드에 🚀 뱃지만
붙고 수치에서는 빠지므로, 도입이 끝나면 `'live'` 로 바꾸고 `hours` 를 채우면 됩니다.

### 카드 이미지 교체
`assets/shots/` 에 프로젝트별 이미지 17장이 들어 있습니다.
현재 이미지는 **실제 운영 화면을 재현한 목업**이며, 사내 데이터가 들어 있지 않습니다.
그래서 카드마다 `재현 화면` 표시가 붙습니다.

실제 스크린샷으로 바꾸려면 **같은 파일명으로 덮어쓰기만** 하면 됩니다.
(권장 비율 **16:10**, 예: 1600×1000)
전부 실제 화면으로 교체했다면 `index.html` 의 `const REPRO_BADGE = true;` 를
`false` 로 바꿔 `재현 화면` 표시를 없애세요.

⚠ 실제 화면을 올릴 때는 사번·성명·거래처명·서버 주소가 노출되지 않도록 반드시 마스킹하세요.

### 섹션 영상 교체
각 파트 앞에는 화면 전체 폭의 영상 구간이 하나씩 들어갑니다. 파일은 `assets/sec/` 에 있습니다.

| 파일 | 들어가는 위치 | 내용 |
|---|---|---|
| `problem.webm` / `.jpg` | Ch.01 문제 | 끝없이 흐르는 수기 시트 |
| `spread.webm` / `.jpg` | Ch.02 확산 | 한 점에서 퍼져나가는 네트워크 |
| `effect.webm` / `.jpg` | Ch.04 효과 | 차오르는 막대 그래프 |
| `process.webm` / `.jpg` | Ch.05 방식 | 네 단계를 도는 순환 |
| `tools.webm` / `.jpg` | 도구 | 흐르는 코드 · 터미널 |

- 영상은 **화면에 가까워질 때만** 내려받습니다. 모바일(720px 미만)·데이터 절약 모드에서는
  정지 이미지(.jpg)만 표시됩니다.
- 바꾸려면 같은 파일명으로 덮어쓰세요. 권장 규격 **960×540, 8초 내외 무한 반복, webm 300KB 이하**.
- 문구는 `BANDS` 상수에서 고칩니다. `key` 는 파일명과 같아야 합니다.

### 배경 사진 · 영상 교체
`assets/bg/` 에 배경 소재가 들어 있습니다. 둘 다 직접 만든 것이라 **저작권 제한 없이** 쓸 수 있습니다.

| 파일 | 용도 | 크기 |
|---|---|---|
| `hero.jpg` | 배경 사진 (항상 표시 · 영상 미재생 시 대체) | 2400×1350 · 120KB |
| `hero.webm` | 배경 루프 영상 (12초 무한 반복) | 1280×720 · 495KB |

두 소재 모두 **직접 만든 시스템 화면들을 원근으로 배치한 "화면 벽"** 입니다.
영상에서는 화면들이 세로로 천천히 흘러갑니다. 글자가 놓이는 왼쪽은 비워 두었습니다.

- 영상은 **화면 폭 900px 이상 + 모션 최소화 설정이 꺼져 있을 때만** 재생됩니다.
  모바일·데이터 절약 모드에서는 사진만 보여 데이터 낭비가 없습니다.
- 다른 사진/영상으로 바꾸려면 **같은 파일명으로 덮어쓰기**만 하면 됩니다.
  무료 소재는 [Unsplash](https://unsplash.com) · [Pexels](https://pexels.com) · [Pixabay](https://pixabay.com)
  (모두 상업적 이용 무료, 출처 표기 불필요)에서 `factory automation`, `industrial robot`,
  `conveyor belt` 등으로 검색하면 됩니다.
- 배경이 밝은 사진이면 글자가 안 읽힐 수 있습니다. `index.html` 의 `.bgmedia::after` 안
  `rgba(14,17,20,.60) → .80 → .94` 숫자를 키우면 더 어두워집니다.

### 연락처 채우기
`CONTACT` 배열의 `value` 와 `link` 를 채우면 **채운 항목만** 마지막 섹션에 나타납니다.
지금처럼 전부 비어 있으면 연락처 블록 자체가 표시되지 않아 미완성처럼 보이지 않습니다.

⚠ 공개 사이트입니다. 사내 메일이 아닌 개인 연락 수단만 넣으세요.

## 2. 보안 원칙

이 저장소는 공개됩니다. 아래는 **절대 넣지 마세요.**

- 관리자 계정 / 비밀번호
- Apps Script 배포 URL, 실제 앱 주소
- 사내 IP · 네트워크 공유폴더 경로
- 사내 이메일 주소

각 카드는 실제 링크 대신 `🔒 사내 운영 중 (비공개)` 뱃지로 표시됩니다.

## 3. GitHub Pages 배포

이 파일들을 `sugilyang.github.io` 저장소의 **루트**에 올리면 `https://sugilyang.github.io` 로 열립니다.

```bash
# 새 저장소(sugilyang.github.io)를 만든 뒤
git clone https://github.com/SugilYang/sugilyang.github.io.git
cd sugilyang.github.io

# 이 저장소의 index.html, assets/, .nojekyll 을 복사해 넣고
git add .
git commit -m "포트폴리오 홈페이지 추가"
git push origin main
```

저장소 **Settings → Pages → Source: Deploy from a branch → main / (root)** 로 설정하면 됩니다.

기존 하위 저장소(`/loto`, `/gps` 등)는 각각 별도 저장소의 Pages로 서비스되므로
루트 저장소에 이 파일을 올려도 **경로가 겹치지 않습니다.**
단, `sugilyang.github.io` 저장소 안에 `loto/`, `gps/` 같은 **같은 이름의 폴더를 만들지는 마세요.**
(루트 저장소의 폴더가 하위 저장소 Pages보다 우선하여 덮어씁니다.)

## 4. 수치에 대하여

Ch.04 의 절감 시간·환산 구축비는 담당자 실측과 국내 개발 외주 플랫폼의 공개 평균 단가를 근거로 한
**추정치**이며, 페이지 안에 산출 근거를 함께 표기했습니다. 실제 값이 확인되면
`projects` 의 `hours` / `est`, `BARS`, `NOTES` 를 수정하세요.

## 5. 화면 효과

스크롤에 반응하는 요소들입니다. 모두 `index.html` 아래쪽 렌더링 코드에 있으며,
운영체제의 **'모션 줄이기'** 설정이 켜져 있으면 전부 자동으로 꺼집니다.

- 첫 화면 — 마우스에 반응하는 홀로그램 메시 그라데이션, 제목 타이핑 회전, 프롬프트 데모 자동 재생
- 히어로 패럴랙스 — 스크롤하면 첫 화면이 밀려 올라가며 옅어짐
- Ch.05 — 화면에 들어오면 AI 협업 대화가 한 줄씩 재생되고 결과 카드가 뜸
- 섹션 진입 시 흐림 → 선명 등장 (카드는 순차 지연)
- 숫자 카운트업, Before→After 막대 채우기
- Ch.02 타임라인 — 스크롤 진행에 맞춰 선이 차오르고 단계가 하나씩 켜짐
- 프로젝트 카드 — 마우스 방향으로 기울고 커서 위치에 빛이 따라다님
- 기술 스택 — 무한히 흐르는 띠 (마우스를 올리면 멈춤)
- 오른쪽 섹션 인디케이터, 상단 진행 바, 커서 글로우
- 배경 — 오로라 그라데이션 + 데이터 흐름 네트워크 + 화면 벽 영상
- 파트마다 전면 폭 영상 구간 + 큰 제목이 단어 단위로 마스크에서 올라옴
- 설명 글은 색 띠가 훑고 지나가며 나타남
- 빠르게 스크롤하거나 목차로 건너뛰어도 지나친 요소가 숨겨지지 않도록 보정
